# Skill 42

Skill Claude Code d'assistance pédagogique pour l'École 42 (`/42 <mode> [options] <sujet>`).

Le skill est installé dans `.claude/skills/42/` : il est chargé automatiquement par Claude Code dans ce dépôt.

Pour l'utiliser ailleurs, copiez le dossier dans `~/.claude/skills/42/` (skill personnel) ou dans `.claude/skills/42/` d'un autre projet.

Exemples : `/42 doc --work malloc`, `/42 review ./libft`, `/42 exam`, `/42 help`.
